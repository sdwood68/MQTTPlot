# MQTTPlot 0.8.3 Roadmap Review

## Summary

The 0.8.3 roadmap items are already substantially implemented in this codebase.
The time-zone dropdown bug was in the admin page render path, not in the 0.8.3
operational tooling. That bug is now patched in `mqttplot/app.py`.

## Roadmap item status

### Implemented

- Firewall rule handling in installer
  - `install_service.sh` checks for UFW and, when active, opens
    `${FLASK_PORT}/tcp`.
  - This is slightly better than the roadmap text because it follows the
    configured port instead of assuming `5000`.

- Installer includes `sqlite3`
  - `install_service.sh` installs `sqlite3` via `apt-get`.

- `mqttplot reset-admin-password`
  - Implemented in `mqttplot/cli.py` as `cmd_reset_admin_password()`.

- `mqttplot reload`
  - Implemented in `mqttplot/cli.py` as `cmd_reload()`.
  - Current behavior is a service restart, which is appropriate because it
    reloads `secret.env` through systemd.

- `mqttplot status`
  - Implemented in `mqttplot/cli.py` as `cmd_status()`.

- `mqttplot db-info`
  - Implemented in `mqttplot/cli.py` as `cmd_db_info()`.

- `mqttplot backup` with ZIP rotation
  - Implemented in `mqttplot/cli.py` as `cmd_backup()`.
  - Creates ZIP archives and prunes older archives according to `--keep`.

- `/api/health`
  - Implemented in `mqttplot/app.py`.
  - Returns app version, MQTT status, and metadata/data DB path existence.

### Newly fixed during this pass

- Admin time-zone dropdown population
  - Root cause: `index()` did not pass `current_tz`, `tz_list`,
    `current_broker_host`, `current_broker_port`, or
    `current_broker_topics` into `templates/index.html`.
  - Fix applied: add `get_time_zone_choices()` and pass those values from the
    route.

## Minor observations

These are not blockers for 0.8.3, but they are worth noting.

- Backup consistency
  - `mqttplot backup` copies live SQLite files directly.
  - For a busy production system, a future improvement could use SQLite's
    backup API or a brief service stop for a fully consistent snapshot.

- Health endpoint depth
  - `/api/health` currently reports path existence and MQTT state, which is
    appropriate for basic monitoring.
  - A future enhancement could add writable checks, DB open checks, and last
    ingest timestamps.

- Reload naming
  - `mqttplot reload` currently performs `systemctl restart mqttplot`.
  - That behavior is operationally correct, but the help text could explicitly
    say "restart to reload `secret.env`" to avoid ambiguity.

## Recommendation

For 0.8.3, the operational tooling roadmap is effectively complete. The next
practical step would be to treat 0.8.3 as stabilization: fold in the time-zone
fix, perform a quick installer/CLI smoke test, and then either tag 0.8.3 or
continue directly into the 0.9.x JSON payload work.
